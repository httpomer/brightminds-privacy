# Bright Minds — Privacy Policy

The public privacy policy for the **Bright Minds** Android/iOS app
(`com.nthsol.brightminds`), hosted with GitHub Pages.

Live at: https://httpomer.github.io/brightminds-privacy/

This repository contains only the published policy page. The app source is
kept in a separate private repository.

To update the policy, edit `index.html` and push — GitHub Pages redeploys
automatically within a minute or so.
